# 高校智慧就业大数据平台（前端示例）

本仓库包含一个纯前端实现的高校智慧就业大数据平台原型，覆盖学生端、HR端、教师端、管理员端主要界面。项目采用原生 HTML/CSS/ES Module 组织，并在浏览器侧通过本地状态与 `localStorage` 模拟完整业务流。

## 功能亮点

- **全局状态管理**：在 `src/state/store.js` 中实现轻量 Store，支持订阅、持久化和跨界面状态共享（收藏、投递、审核等操作即时生效）。
- **学生端**：
  - 职位筛选支持行业/城市/薪资/学历组合，收藏与一键投递会更新“我的投递”与通知中心。
  - 投递面板提供时间线、消息补充、附件上传（模拟），并保留至下一次访问。
  - 简历中心支持逐项编辑、附件增删、自动计算完整度进度环。
  - 活动列表可报名/取消、更新入场指引，并生成提醒通知。
  - 通知中心支持分类筛选、已读管理与批量操作。
- **HR 端**：
  - 职位管理具备新增、编辑、批量上线/复制、数据加速（曝光/浏览模拟）等互动。
  - 候选人面板支持状态流转、邀约模板发送、关键词/阶段筛选。
  - 校招活动面板可在线编辑报名表并提交审核。
- **教师端**：活动创建表单、企业报名审核、报名名单导出、签到二维码模拟，以及就业看板的筛选统计、企业考核黑白名单标记。
- **管理员端**：用户角色调整、启用停用、操作日志筛选导出，以及教师/HR 面板概览快速跳转。
- **交互反馈**：统一的 Toast 组件（`src/components/toast.js`）提供操作提示。

## 使用方式

1. 克隆或下载项目后，使用任意静态服务器启动（示例：`npx serve`、`python -m http.server` 或 VSCode Live Server），然后访问根目录下的 `index.html`。
2. 顶部导航用于切换角色，二级导航切换子模块；URL 哈希结构为 `#角色/页面/(可选参数)`。
3. 所有数据读写均在浏览器端模拟并存入 `localStorage`，刷新仍可保留操作结果；如需重置，可在开发者工具执行 `window.__careerStore.actions.reset()`。

## 目录结构

```
index.html           # 页面骨架与脚本入口

src/
  main.js            # 路由与导航控制、Store 订阅
  data/mockData.js   # 初始数据与导航配置
  state/store.js     # 前端状态管理与业务动作
  components/
    toast.js         # Toast 组件
  views/             # 各角色视图模块（ESM）

styles/
  reset.css
  main.css           # 统一样式体系（卡片、表格、进度环、Toast 等）
assets/
  avatar.svg
```

## 后续可拓展

- 接入真实后端：将 `actions` 内的模拟逻辑替换为 API 请求，并补充错误/加载态。
- 引入现代框架：可迁移至 Vite + Vue/React，复用当前数据结构与样式体系。
- 自动化测试：为状态动作与关键页面编写单元测试或端到端测试，确保交互稳定性。
- 多语言与无障碍：结合 i18n、键盘导航提示提升可用性。
